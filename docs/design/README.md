# Designs

One file per `size:l` issue designed before it is built, `<date>-<topic>.md`: the intent in the maintainer's words,
what the original does, goals, non-goals, constraints, verification, what is decided / guessed / open, and the
builder's questions with their answers. Approved by the maintainer before the plan is written into the milestone's
file. The process: [Designing a large issue](../agents/workflow.md#designing-a-large-issue).
